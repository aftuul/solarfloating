Integrasi Mikrokontroler ESP32
Sensor Suhu DHT22, Kelembaban Udara & Tanah, Aktuator
ESP32 menjalankan WebSocket Server pada port 81. Pastikan laptop/HP berada di jaringan WiFi yang sama dengan ESP32.
Status ESP32: SIMULASI STANDALONE RSSI: -- dBm Uptime: --
Koneksi dashboard via MQTT over WebSocket. Cocok untuk monitoring jarak jauh/cloud internet (ESP32 dan browser tidak harus berada di jaringan WiFi yang sama).
Info Port ESP32 vs Browser: Browser memakai koneksi WebSocket aman (WSS port 8084 atau 8884). Di ESP32 Arduino, gunakan broker host yang sama dengan port standar TCP MQTT 1883.
Sambungkan ESP32 langsung ke port USB laptop Anda menggunakan kabel data. Browser Chrome / Edge dapat langsung membaca stream data serial sensor (115200 baud) tanpa konfigurasi WiFi!
*WebSerial didukung di Google Chrome, Microsoft Edge, dan Opera versi desktop.
